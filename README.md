# DalamudPlugins

MusicYYin 的 Dalamud 第三方插件聚合仓库。一个库链可以同时收录多个插件，后续新插件会继续追加到 `pluginmaster.json`。

## 第三方库链

在 Dalamud 设置的“实验性功能 → 自定义插件仓库”中添加：

```text
https://raw.githubusercontent.com/MusicYYin/DalamudPlugins/main/pluginmaster.json
```

保存后，可在插件安装器中搜索本仓库收录的插件。
